# RoboSolve

RoboSolve is a high-end Open Innovation Robotics platform prototype.

## Concept

Real-world problem → idea → robot design → simulation → prototype → validation → deployment.

## Included in this starter

- Premium responsive landing page
- Problem marketplace
- Search and category filtering
- Problem detail modal
- Submit-problem workflow
- Solution network
- Robotics Lab simulator prototype
- Robot configuration and telemetry UI
- Team discovery
- Responsive mobile navigation

## Run locally

Requirements:
- Node.js 18+

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```
